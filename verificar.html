Verificar documento

Cole o código que aparece no rodapé do documento. Se ele estiver registrado, você tem a confirmação de que o documento é o original e não foi alterado.

Como funciona
1
Ao criar um relatório, o Fieldo gera um código único a partir do conteúdo e guarda com data e hora. Mudar qualquer detalhe do documento produziria um código diferente.
2
O código aparece no rodapé do relatório. Não é possível alterar o documento sem que o código deixe de bater.
3
Qualquer pessoa pode conferir aqui — não precisa de conta nem de aplicativo.
